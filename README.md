# SupportIQ

SupportIQ is an AI-powered customer support platform where organizations can manage support tickets, agents, customers, knowledge-base documents, and source-backed AI reply suggestions.

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- React Router
- Redux Toolkit
- RTK Query
- React Hook Form
- Zod

### Backend

- Node.js
- Express.js
- TypeScript
- Prisma
- PostgreSQL
- JWT authentication
- Refresh token rotation
- Zod validation

### Infrastructure

- Docker
- Docker Compose
- Redis
- PostgreSQL

## Current Features

- User registration
- User login
- JWT access tokens
- Hashed refresh tokens
- Refresh token rotation
- Logout/session revocation
- Protected routes
- Organization creation
- Organization member management
- Organization-level RBAC
